title:5000 sq.ft QS Estimation Project
description:
This project is a detailed Quantity Surveying and Estimation project for a 5000 sq.ft ground-floor residential home with an adopted site size of 50 ft × 100 ft. The report follows a complete civil engineering estimation workflow, including drawings, quantity summary, rate analysis, bill of quantity, preliminary estimate, total cost, and rate per square foot. The project includes calculations for earthwork, RCC gate columns, RCC rectangular columns, brickwork in superstructure, RCC plinth beams, RCC roof beams, roof slab, DPC, plastering, flooring, electric work, timber work, water supply and sanitary work, and miscellaneous works. The quantities are adjusted from the base project using an area factor, while rates follow the original rate-analysis method. This project helps demonstrate how residential construction cost is estimated through drawings, sectional details, quantity takeoff, and BOQ preparation.
